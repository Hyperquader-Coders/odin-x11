# Spec: odin-x11

## Packages

```
xlib/    package xlib: generated by runic from xlib/rune.yml
xtest/   package xtest: generated by runic from xtest/rune.yml
```

Import through the `x11` collection: `import "x11:xlib"`, `import "x11:xtest"`.

## Surface

`xlib`: every public declaration of `X11/Xlib.h`, `X11/Xutil.h`, `X11/XKBlib.h` and
`X11/Xatom.h` (libX11 1.8.7) and of the headers they include (`X11/X.h`, `X11/keysym.h`,
`X11/keysymdef.h`, `X11/extensions/XKB.h`, `X11/extensions/XKBstr.h`), under the C names, plus
the hand fixes in [PATCHED.md](PATCHED.md). Left out:

| what | why |
|---|---|
| names starting with `_` (`_XData`, `_Xmblen`, `_X_EXPORT`) | private to the library, as `Xlib.h` says; the struct tags behind public typedefs (`_XDisplay`) stay |
| function-like macros (`DefaultRootWindow(dpy)`) | a macro is not a symbol; each has an `X` function (`XDefaultRootWindow`) |
| `AllPlanes` | `~0UL` is past what a constant holds; `XAllPlanes()` returns it |

`xtest`: every public declaration of `X11/extensions/XTest.h` and `X11/extensions/xtestconst.h`
(libXtst 1.2.3), under the C names, linking `system:Xtst`. Its Xlib types are `xlib`'s
(`xlib.Display`, `xlib.Window`, `xlib.Bool`, `xlib.Status`); `XDevice` and `XInputClassInfo`,
the libXi types of `XInput.h` that the device procedures take, are its own
([DECISIONS §4](DECISIONS.md#4-one-package-a-shared-library)).

## Types

| C | Odin |
|---|---|
| `Bool`, `Status` (`#define … int`) | `Bool :: i32`, `Status :: i32`, in `xlib`; `xtest` writes `xlib.Bool`, `xlib.Status` |
| `XID`, `Window`, `Atom`, `Time`, `KeySym`, … | the C typedefs, on `u64` |
| `long`, `unsigned long` | `i64`, `u64` (x86_64 Linux) |
| `char *` | `cstring`, except the buffers in [PATCHED.md](PATCHED.md), which are `[^]u8` |
| `T *` parameter | `^T`; a run listed under `arrays:` in the package's `rune.yml` is `[^]T` |
| `T name[N]` parameter | `^T`, or `[^]T` where listed: C passes the pointer |
| `XEvent` and the other unions | `struct #raw_union`, the C size (`XEvent` is 24 `long`s) |
| macro constants | untyped numbers and strings |

## Version

`README.md` records the libX11 and libXtst versions the binding was generated from. Neither has
a version macro, so `make lint` (`scripts/check-generated.sh`) compares the records with
`pkg-config --modversion x11` and `xtst`, and `make test` checks `X_PROTOCOL` (11),
`XlibSpecificationRelease` (6) and `XTestMajorVersion` (2).
